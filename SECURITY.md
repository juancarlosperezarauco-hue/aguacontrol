# Seguridad

No publique credenciales, archivos `.local`, respaldos SQL `.bak`, datos personales reales, evidencia de campo ni claves de proveedores de pago.

Para reportar una vulnerabilidad, no abra un issue público con detalles sensibles. Contacte al responsable del repositorio de manera privada e incluya una descripción, impacto y pasos mínimos de reproducción.

La aplicación actual usa pagos simulados. Cualquier integración de pagos reales requiere revisión de seguridad antes de almacenar o transmitir datos.
