# Población demostrativa de clientes

Estos CSV contienen **únicamente datos ficticios** para una instalación de demostración de AquaControl. Cada registro utiliza el prefijo `DEMO-` y no representa personas, cuentas ni medidores reales.

La carga incorpora ocho clientes con cuenta de abonado, conexión asociada a un Código Fijo SIG, contrato vigente y medidor cuando corresponde. Los servicios `CORTADA` y `PENDIENTE_INSTALACION` permiten verificar los filtros operativos del mapa.

No use estos archivos para una operación real. Para cargar el padrón oficial, parta del formato principal de `templates/carga-comercial` y valide los datos con la entidad responsable.
